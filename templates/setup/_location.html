Where is your receiver?

Set the coordinates of the radar receiver site. While you do, the spectrum analyser will scan your RF environment to improve tower search results.

{# Address first, because it is the only way to fill the coordinates without reading them off a map: the node is served over plain HTTP, so the browser Geolocation API behind "Use my location" below is unavailable to it. The lookup runs server-side via /towers/geocode, which that constraint does not reach. Nothing is gated on this. The coordinate boxes stay editable after a lookup and Find Towers reads only them, so typing coordinates by hand works exactly as it did before this row existed. #}
{# Both halves matter: the geocoder is pinned to the US, so a non-US address usually comes back as "no match", which reads as a typo unless the box has already said otherwise. Worse, a foreign place name colliding with a US one ("Toronto, Ontario") returns a confident street-level match in the wrong country. That is measured, not theoretical, so the matched address still has to be checked by the owner. #}

US addresses only for now. You can also enter coordinates directly below.
